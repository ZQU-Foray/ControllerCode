# 移除后端转发层验证

MotorGroup 不再经由 detail::MotorBackend 转发，直接持有编译期选定的品牌适配器。
删除 dji/DjiMotorBackend.hpp 与其测试影子头；型号→适配器映射收敛为
dji/DjiMotorModelMap.hpp 的 MotorAdapterFor 特化（档案与原生减速比在品牌侧装配）；
通道占用检查（共享占用表 + 同通道第二组 Init 失败）移入通用 MotorGroup.hpp。
任务保持 MotorGroup<MotorModel, N> 选型，仅新增一行品牌映射包含。

## 结果

- 宿主机 12 项测试全部通过（原 11 项 + 新增 brand_extension）：型号映射、实例
  独立、通道冲突、非法数量编译期拒绝与控制输出回归全部覆盖。
- brand_extension 以独立最小非 DJI 适配器 + 虚拟型号（static_cast<MotorModel>(254)）
  验证扩展机制：仅包含通用 MotorGroup.hpp 即可编译运行，通道占用对非 DJI 适配器
  同样生效。
- 配置阶段新增检查：未包含任何品牌映射时合法型号同样无法实例化（映射是唯一入口）；
  边界检查更新为"任务允许品牌映射包含，禁止协议/适配器/驱动直接引用"，并将
  MotorGroup.hpp 纳入品牌无关边界清单。
- 模拟构建以同名映射头替换旧的影子后端头，机制不变（Support 优先包含路径）。
- WSL-Debug、WSL-Release 固件均构建通过，-Wextra -Werror 零告警。
